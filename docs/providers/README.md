# Download providers

Choose where Music Bot downloads audio from and follow that provider's setup guide.

- [Soulseek via slskd](soulseek.md) — download albums and tracks from Soulseek.

Soulseek is currently the only supported download provider.
[Importing your own ZIP archives and audio files](../usage.md#import-an-album) works without one.

Send `/provider` to check the configured provider's status. After setup, send your music link again.
